eegUtils is the only reliable R package I've found for plotting topo maps
But I found trying to install eegUtils to be extremely difficult,
especially on Mac
Here's what finally worked:

If trying to install with the following line is crashing:

remotes::install_github('craddm/eegUtils')

and it's looking for some version of gfortran in /opt/gfortran

Go here and find the version it's looking for
https://github.com/fxcoudert/gfortran-for-macOS/releases

right click copy the link for the .dmg file

cd to the downloaded .dmg in a terminal

Run the following

curl -L -o gfortran.dmg
https://github.com/fxcoudert/gfortran-for-macOS/releases
hdituil attach gfortran.dmg
cd Volumes/gfortran
sudo installer -pkg name_of_pkg.pkg -target /

Try and install eegUtils again with:
remotes::install_github('craddm/eegUtils')

It may crash and tell you it can't find some directory
manually go into /opt/gfortran/lib/gcc/aarch64-apple-darwin**
    and rename this ^ dir to match the directory it can't find
